Why PSCapture

A capture card, without the capture card.

Everything runs on hardware you already own: the console, your network and your PC.

A real camera device

A DirectShow source filter named PS5 Capture. Any app that can open a webcam can open your console.

Straight from the display engine

The payload reads the console's scan-out buffer and sends raw NV12 frames. Nothing is re-encoded, so nothing waits for an encoder.

One file, one window

PSCapture.exe installs the driver, sends the payload, registers it in the autoloader and connects, all on its own.

Recovers by itself

Console still off? It retries every 2 seconds. Stream dropped? It reconnects. You don't have to babysit it.

Live tuning

Colour gain and horizontal shift apply in about a second and are saved in pscapture.ini.

Stays on your network

No accounts, no cloud relay, no Remote Play. Frames go from the console to your PC and nowhere else.

How it works

Three small pieces, one camera.

A payload on the console, a feeder and a driver on the PC. The apps you already use just see a webcam.

Before you start

What you need.

On the PS5

  • A jailbroken consoleBuilt and tuned on firmware 13.60. See the FAQ for other versions.
  • Payload loader on TCP 9021elfldr-style, as in every current jailbreak setup.
  • Anonymous FTP on TCP 2121The app reads and writes a few files on the console.
  • pldmgr autoloader optionalStarts the payload on every boot, so you never deploy by hand.

On the PC

  • Windows 10 or 11, 64-bitThe camera is a DirectShow device, so the PC side is Windows-only.
  • Same network as the consoleWired recommended. Gigabit is plenty for 1080p at 30 fps.
  • Admin rights, onceTo register the camera for every program on the machine.
  • PSCapture.exe from ReleasesOne single file: the payload and the driver are inside it.
Setup

From zero to live in five steps.

After step 2 you mostly watch: the app does the rest and tells you what it's doing.

  1. Jailbreak the console

    Run your usual jailbreak so the payload loader (9021) and FTP (2121) are up.

  2. Double-click PSCapture.exe

    Windows asks “Do you want to allow this app to make changes to your device?”. Click Yes. The app elevates itself, no right-click needed.

  3. Check the IP

    The default is 192.168.0.36. If your PS5 has a different address, type it in PS5 IP and press Apply. It's remembered. You can find it on the console under Settings → Network → Connection Status → View Connection Status.

  4. Hands off

    On the first run the app installs the driver, then sends the payload and connects. The console shows “PSCapture is streaming on:5599” and the status pill turns green: STREAMING.

  5. Pick PS5 Capture in your app

    Discord, OBS or ffmpeg. See where to find it below.

Daily use

Open it and play.

every day

Open PSCapture.exe and accept the UAC prompt. With the autoloader the stream starts by itself.

  • Deploy payload: re-sends the payload by hand, after a reboot without autoloader.
  • Install driver: re-registers the camera if the log shows a driver error.
  • STOP or closing the app: the camera freezes on the last frame and stays listed.
gain

Colour (chroma) strength.

  • 1.0 is raw and correct.
  • Only touch it if colours look off.
shift px

Moves the picture left or right.

  • Even numbers only: an odd value swaps the colours.
  • The console's title text makes a good reference.

Build from source

Two halves, two toolchains.

The repository holds sources only; ready-made binaries are on Releases. The full walkthrough (toolchain install, checks, pitfalls) is in BUILD.md.

Step 1 · console

Payload → pscapture.elf

Needs Docker and the PS5 payload SDK image (prospero-clang; any tag works, here ps5sdk:18).

$ docker run --rm -v "$PWD/payload:/payload" -w /payload ps5sdk:18 make
Step 2 · PC

App and driver → pscapture.exe + pscapture.dll

Needs MinGW-w64 (gcc + windres). The order matters: the .res embeds the driver and the payload exactly as they are on disk.

# from the repo root
cp payload/pscapture.elf pc/
cd pc

# 1) the capture-card driver (DirectShow source filter)
gcc -O2 -shared -static -static-libgcc -o pscapture.dll ps5cam.c \
    -lole32 -loleaut32 -luser32 -ladvapi32 -lws2_32

# 2) bundle icon + payload + driver into the resource object
windres pscapture.rc -O coff -o pscapture.res

# 3) the single-file app
gcc -O2 -mwindows -o pscapture.exe pscapture.c pscapture.res \
    -lws2_32 -lshell32 -ladvapi32 -luxtheme

The two classic mistakes. Rebuilding the DLL or the payload after windres leaves the old ones inside the exe, so always go DLL → windres → exe. And -static -static-libgcc on the DLL is mandatory: without it Windows may refuse to load the driver with “the specified module could not be found” (missing MinGW runtime).

FAQ

Questions.

Does it work on firmwares other than 13.60?

The PC side works with any firmware: the app and the driver only use TCP, FTP and shared memory. The console payload is the version-specific part. It was built and tuned on 13.60 using display-engine anchors found on that firmware. Other versions may need a small porting pass to find the same anchors. Open an issue with your firmware version.

Why is the camera 720p in Discord calls?

That's Discord's voice engine: it requests 1280×720 from every camera. In OBS, PS5 Capture runs at the full 1920×1080. Discord's screen-share goes up to 1080p60 with Nitro.

Do I need a capture card or Remote Play?

No. PSCapture never touches Remote Play. The payload reads the display engine on the console itself and sends raw frames over your LAN.

Does it capture game audio?

Not yet. PSCapture is video-only for now.

Does it work on macOS or Linux?

The PC side is Windows-only, because the camera is a DirectShow device.

How do I uninstall it?
  1. Close the app.
  2. Run rundll32 "%ProgramFiles%\PSCapture\pscapture.dll",DllUnregisterServer to remove the camera.
  3. Delete C:\Program Files\PSCapture.
  4. Optional, on the console: delete /data/pldmgr/payloads/pscapture/ so the autoloader stops starting it.
